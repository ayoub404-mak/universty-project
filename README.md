# myuniversity – Modern Educational Website Template

**myuniversity** is a responsive, multi‑page educational website template built with **HTML5**, **CSS3**, and a simple PHP form handler.  
It’s ideal for schools, universities, academies, or online learning platforms looking for a clean and modern web presence.

---

## Features

-  Fully responsive design  
-  Clean, modern UI  
-  Multi‑page structure (Home, About, Courses, Blog, Contact)  
-  Organized CSS components  
-  Simple PHP form handler  
-  Easy to customize and extend  

---

##  Project Structure

```
myuniversity/
│
├── index.html            # Homepage
├── about.html            # About the university
├── course.html           # Courses and programs
├── blog.html             # Blog / news page
├── contact.html          # Contact form page
│
├── former-hander.php     # Basic PHP form handler
│
├── style.css             # Main stylesheet
│
└── eduford_img/          # Images and assets
```

---

## Pages Overview

| Page | Description |
|------|-------------|
| **index.html** | Main landing page with hero section and navigation |
| **about.html** | Information about the university or institution |
| **course.html** | List of available courses or programs |
| **blog.html** | Articles, updates, or announcements |
| **contact.html** | Contact form + contact details |
| **former-hander.php** | Handles form submissions (basic PHP) |

##  Technologies Used

---

##  Installation & Usage

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/myuniversity.git
   ```
2. Navigate into the project:
   ```bash
   cd myuniversity
   ```
3. Run locally:
   - Open `index.html` directly in your browser  
   - Or use a local PHP server:
     ```bash
     php -S localhost:8000
     ```

---

##  Customization

You can modify:

- Colors, fonts, layout → `style.css`  
- Images → `eduford_img/`  
- Text content → HTML files  
- Form logic → `former-hander.php`
